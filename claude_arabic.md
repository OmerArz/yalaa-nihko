# Spoken Arabic Tutor App (Jerusalem Dialect) - Project Specification

## 1. Project Overview
This project is a personal Progressive Web Application (PWA) designed for learning Spoken Arabic (Jerusalem / Urban Palestinian-Israeli dialect - להג ירושלמי) using precise Hebrew transliteration (תעתיק מדויק). 

The app features real-time live feedback, dual learning modes (structured scenarios + daily free-flowing chat), voice-to-text interaction, an offline local dictionary/phrase repository, and web push notifications for daily study reminders. It is designed to run locally during development and be deployed for free on Vercel for mobile access.

---

## 2. Core Architecture & Tech Stack

- **Framework**: Next.js (App Router) with TypeScript & React.
- **Styling**: Tailwind CSS (Mobile-first, responsive, clean UX for phone & desktop).
- **PWA & Notifications**: `@ducanh2912/next-pwa` (or Next.js PWA setup) + Web Push API / Service Workers for daily mobile push notifications.
- **Hosting**: Vercel (Free Tier).
- **AI Integration**: Anthropic SDK (`@anthropic-ai/sdk`) using `ANTHROPIC_API_KEY`.
- **Local Knowledge Base & RAG**:
  - Embedded JSON/SQLite dataset of 3,000+ Jerusalem dialect vocabulary words, common idioms, and daily sentence structures.
  - Context Injection Engine (RAG): Feeds relevant vocabulary from the local database into Claude prompts based on active practice scenarios.
- **Audio & Speech**:
  - **Speech-to-Text (STT)**: Native browser `Web Speech API` (with fallback microphone recording interface).
  - **Text-to-Speech (TTS)**: Native browser `SpeechSynthesis` API set to Arabic (`ar-SA` / `ar-IL`).
- **Database / Local Storage**: `IndexedDB` or `localStorage` for saving user vocabulary mastery, progress, conversation history, and user settings.

## 3. Linguistic & Pedagogical Rules (System Prompt Instructions)

The AI engine driving the app MUST strictly follow these rules:

### A. Dialect & Vocabulary
- **Target Dialect**: Jerusalem / Urban Central Levantine Spoken Arabic (להג ירושלמי/מרכזי).
- **Strict Constraint**: Never use Standard Classical Arabic (פוסטחה / MSA). Use everyday conversational vocabulary (e.g., *הלאק* for now, *אישי* for something, *בדי* for I want, *כמאן* for also/more).

### B. Accurate Hebrew Transliteration (תעתיק מדויק)
All Arabic phrases generated by the AI must include:
1. **Hebrew Transliteration (תעתיק)** with visual markers for precise letters:
   - **ח** for ح (Haa)
   - **ע** for ع ('Ain)
   - **ט** for ط (Taa)
   - **צ** for ص (Saad)
   - **ק** for ق (Qaf) — always kept as the primary root letter in transliteration, immediately followed by the Jerusalem urban glottal-stop pronunciation in square brackets with **א** (e.g. `קַהְוֶה [אַהְוֶה]` = coffee, `הַלַּק [הַלַא]` = now, `קָרִיב [אָרִיב]` = close). Never write only the א-form without the ק-root form, and never write only the ק-form without the `[א...]` bracket.
   - **ז/ד** for ذ / ض depending on local urban pronunciation.
2. **Original Arabic Script** (as secondary text, for future learning).
3. **Hebrew Translation**.
4. **Vocabulary Breakdown**: under the full Hebrew translation, a short list of 2-4 key words from the sentence in the format `transliteration – Hebrew meaning`, following the same ק/[א] transliteration rule.

### C. Live Immediate Feedback Loop (תיקון מיידי בלייב)
After EVERY user input (voice or text), the AI response must be formatted into two distinct sections:
1. **Feedback & Correction Block**:
   - Check grammar, vocabulary, and pronunciation accuracy of the user's sentence.
   - Show corrected transliteration + explanation in Hebrew.
   - Highlight what was fixed.
2. **Conversational Continuation**:
   - Respond in Spoken Arabic (Transliteration + Arabic script + Hebrew translation).
   - Include the Vocabulary Breakdown block (see section B.4).
   - Ask an engaging follow-up question/hint to keep the conversation flowing. In the UI, this hint is hidden by default behind a "💡 הראה רמז" toggle so the student attempts the answer before revealing it.

## 4. Key Features & User Interface

### Module 1: Daily Life / Free Chat Mode (שיחת יומיום חופשית)
- Free-form conversation where the user talks about their day, experiences, or thoughts.
- AI adapts to the user's vocabulary level and actively fixes grammar in real time.

### Module 2: Scenario Practice Mode (סימולציות מובנות)
- Interactive dialogues based on real-world situations:
  - Ordering food at a restaurant / café
  - Asking for directions in the street
  - Haggling / Shopping at the market
  - Small talk with neighbors or colleagues
  - Emergency / Getting help
- Pulls scenario-specific vocabulary from the local repository.

### Module 3: Local Vocabulary & Flashcards (מילון ושינון מילים)
- Offline browser for the 3,000+ Jerusalem word repository.
- Flashcard mode for quick spaced-repetition practice without AI API calls.
- Mastery tracking (% of local repository mastered).

### Module 4: Daily Reminders (תזכורות יומיות PWA)
- Custom push notification settings (e.g., reminder every day at 20:00).
- Utilizes Web Notifications & Service Worker to send local or Vercel Cron-triggered alerts to the mobile device home screen.

### Module 5: Audio Practice (הקלטה ושמע)
- Big push-to-talk button for voice input.
- Audio playback button next to every Arabic sentence to hear native-like audio via browser TTS.

## 5. Visual Design, UI & Color Palette

- **Theme Style**: Mediterranean / Israeli Warm Natural Theme (ים-תיכוני חם וטבעי).
- **Color Palette**:
  - **Primary**: Deep Olive Green (`#2D5A27`) - used for headers, main navigation, and active states.
  - **Accent / Highlight**: Warm Gold/Sand (`#D4AF37`) - used for core actions, recording animations, and transliteration emphasis.
  - **Background**: Soft Warm Cream (`#FDFBF7`) for light mode to reduce eye strain.
  - **Feedback Card**: Soft Amber background (`#FEF3C7`) with dark orange border (`#D97706`) for immediate live corrections.
  - **Success / Correct**: Soft Emerald (`#10B981`).
- **Typography**:
  - **Hebrew & Transliteration**: Google Font `Rubik` or `Assistant` (bold, clear, highly legible for reading transliteration on the fly).
  - **Arabic Script**: Google Font `Readex Pro` or `Noto Sans Arabic`.
- **Chat Layout & Component Hierarchy**:
  - Each AI message block MUST visually separate:
    1. **Top Badge/Card**: Live correction / feedback box (if applicable).
    2. **Main Text (Large & Bold)**: Precise Hebrew Transliteration.
    3. **Sub-text (Medium)**: Hebrew Translation.
    4. **Secondary/Collapsible**: Arabic Script.
    5. **Audio Trigger**: Large, easily tappable speaker button next to the transliteration.
- **Bottom Navigation**: Mobile-first bottom bar (Home/Chat, Scenarios, Dictionary/Flashcards, Settings) with a prominent floating central Microphone button for instant voice input.

## 7. מצב יישום נוכחי (עדכון 2026-08-05)

הסעיפים 1-6 לעיל הם המפרט המקורי. להלן מצב היישום בפועל, כפי שנסקר במלואו:

### מה מיושם ומעבר למפרט המקורי
- **בסיסים** (`/basics`): לשוניות אלפבית (29 אותיות), סימונים לשוניים (אותיות כבדות, שווא, כלל ק→א), וכללי הטיות (formula cards עם מורפולוגיה צבעונית).
- **מילון** (`/dictionary`): חיפוש+סינון קטגוריה/רמה, מצב רשימה/פלאשקארד, טבלת הטיות לפעלים.
- **משחקים** (`/games`): SpeedQuiz (10 שאלות מתוזמנות), AudioChallenge (זיהוי לפי שמע), GameFlashcards (20 קלפים).
- **מילות היום** (`/daily-words`): אקורדיון עם סטטוס לחיץ + פירוט AI מורחב + משפט לדוגמה (עם קאש).
- **בוחן יומי** (`/daily-quiz`) ו**רפלקציה יומית** (`/daily-reflection`): לא היו במפרט המקורי כלל.
- **checklist יומי** בדף הבית, יעד יומי מתכוונן, סטטוס מילה (⚪/🟡/🟢), תעתיק לטיני (Arabizi) לצד כל תעתיק עברי.
- **תרגול משפטים** (`/sentences`, נוסף 2026-08-06): מאגר של **221 משפטים** שלמים בערבית ירושלמית (`data/jerusalem_sentences.json`), מסווגים לרמה 1/2 ול-14 קטגוריות, בנויים מעל אוצר המילים הקיים - כולל שימוש בטבלאות ההטיות המלאות (8 גופים) של הפעלים הקיימים לגיוון גופים דקדוקי. תרגום עצמי (לא AI): המשתמש בוחר כיוון (ערבית→עברית או עברית→ערבית), רמה וקטגוריה, כותב תשובה חופשית, לוחץ "הצג תשובה" ומסמן בעצמו ✓/✗. תוצאות נשמרות ב-localStorage (`lib/sentenceStatus.ts`).
- סנכרון Supabase חלקי (word_progress, settings, push subscriptions בלבד).

### עדכון 2026-08-06 (הרחבה שלישית)
מאגר המילים גדל ל-**555 מילים** (מ-429), עם תוספות ממוקדות בפערים אמיתיים: צבעים (10, לא היו קיימים כלל קודם), ימות השבוע (7, לא היו קיימים כלל קודם), בגדים, מקצועות, פריטי בית, איברי גוף, מזג אוויר, רגשות. נוספו גם **8 פעלים חדשים עם הטיות מלאות** (בישל/ניקה/כיבס/רץ/שחה/רקד/צחק/בנה) - סה"כ **75/555 מילים עם הטיות מלאות**. מאגר המשפטים גדל ל-**330 משפטים** (מ-221), כשה-109 האחרונים מבוססים בעיקר על התוכן החדש.

### פערים ידועים מול המפרט/הפוטנציאל המלא
- מאגר המילים הוא 555 מילים, לא 3,000+ כמתוכנן במקור.
- 75/555 מילים (13.5%) כוללות טבלת הטיות מלאה - עדיין רוב הפעלים הלא-common_verbs (בעיקר בקטגוריות אחרות) לא מוטים.
- אין בכלל מילים ברמת קושי 3 ("מתקדם") בדאטה, למרות שהUI מציע לעיתים סינון לפי רמה זו.
- BottomNav במובייל (7 פריטים) לא כולל daily-words/daily-quiz/daily-reflection - נגישים במובייל רק דרך לינקים פנימיים, לא ניווט ראשי.
- Service Worker לא מקדם-קאש את הדפים החדשים (daily-words/daily-quiz/daily-reflection/basics/games).
- reflections ו-daily checklist לא מסונכרנים ל-Supabase (localStorage/IndexedDB בלבד).
- Supabase schema טרם הורץ בפועל; לא נעשה Deploy ל-Vercel.
